iOS • SwiftUI • Lossless ImageIO • Open Source

Export photos & videos with accurate timestamps, timezones, and GPS intact.

Photo Exporter is an on-device iOS utility for inspecting EXIF metadata, correcting missing timezones, organizing exports by date, and transferring originals without recompression to Local Files, Google Drive, Google Photos, or Samba (SMB2) shares.

View Source on GitHub Read Privacy Policy

Built for Photographic Fidelity

Zero cloud intermediaries, zero image bloat, and native protocol implementations directly in Swift.

Lossless Metadata Embedding

Updates EXIF, TIFF, GPS, XMP, and QuickTime creation metadata via CGImageDestinationCopyImageSource without re-encoding image pixels or inflating file sizes. Includes raw TIFF SubIFD parsing for RAW/DNG offsets and explicit PNG XMP compatibility on iOS.

JPEG / HEIC PNG XMP DNG / MOV / MP4

Timezone Inference & Batch Edits

Automatically distinguishes native EXIF dates from Photos app adjustments, detects photos missing timezone offsets, and infers offsets from adjacent shots or location metadata. Apply batch date, timezone, and GPS corrections cleanly.

Offset Inference Batch Editing Map Inspector

Multi-Source Media Browser

Switch seamlessly between the iOS Photo Library, local security-scoped folders, Google Drive folders, and Samba (SMB2) shares—with in-place rename, 90° rotation, deletion, and metadata application.

PhotoKit Local Files Drive & SMB2

Smart Folder & Conflict Resolution

Organize exported assets using customizable tokens (yyyy, yyyy-MM, yyyy/MM). Pre-export analysis skips matching destination files and previews grouped [Destination], [Original], and [Renamed] families.

Dedup Engine Subfolder Tokens Preview & Override

Direct Cloud & Pure-Swift SMB2

Streams uploads straight to Google Drive (uploadType=resumable), Google Photos, or your local NAS via a pure-Swift SMB2 client over BSD sockets—with BGContinuedProcessingTask support and persistent failed-item retry.

Resumable Uploads Pure Swift SMB2 Background Tasks

Fullscreen Viewer & Range Streaming

Features swipeable high-resolution photo zoom, native AVPlayerViewController playback, smooth fullscreen expand-and-rotate transitions, Edited vs. Original comparison, and HTTP Range streaming for remote Google Drive videos.

Zoomable Viewer AVPlayer HTTP Range Stream

100% On-Device & Transparent

Photo Exporter runs no developer servers, collects no analytics, and connects directly from your iPhone to the local folders, SMB shares, or Google accounts you authorize.
